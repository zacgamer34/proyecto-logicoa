# Sistema de Venta de Boletas y Gestión de Sillería (Python Nativo)

Este repositorio contiene la solución de software desarrollada en Python puro (sin dependencias externas) para el diseño y automatización del proceso de venta de boletas, control de sillería mediante matrices bidimensionales y analítica de datos para eventos de tipo Teatro, Deporte y Concierto por medio de manejo de archivos y datos de archivos ya existentes para su ejecucion.

todos los archivos nesesarios para su correcta ejecucion esta en la carpeta archivos
---

## 🚀 Instrucciones de Instalación y Ejecución

El proyecto fue construido con  **cero dependencias externas**. Utiliza únicamente la biblioteca estándar de Python (módulos nativos como `os` o `math` si aplica), por lo que no requiere gestores de paquetes como `pip`.
