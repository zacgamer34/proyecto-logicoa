# Sistema de Venta de Boletas y Gestión de Sillería (Python Nativo)

Este repositorio contiene la solución de software desarrollada en Python puro (sin dependencias externas) para el rediseño y automatización del proceso de venta de boletas, control de sillería mediante matrices bidimensionales y analítica de datos para eventos de tipo Teatro, Deporte y Concierto.

---

## 🚀 Instrucciones de Instalación y Ejecución

El proyecto fue construido bajo la premisa de **cero dependencias externas**. Utiliza únicamente la biblioteca estándar de Python (módulos nativos como `os` o `math` si aplica), por lo que no requiere gestores de paquetes como `pip`.

### Prerrequisitos
* Tener instalado **Python 3.8 o superior** en su entorno local.
